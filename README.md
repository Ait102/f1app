# F1 Season Hub

Веб-приложение с календарём, результатами и зачётами Formula 1 (MVP по ТЗ v0.2).
Данные — открытый API [Jolpica-F1](https://github.com/jolpica/jolpica-f1) (Ergast-совместимый, без ключа, CORS открыт), поэтому бэкенд не нужен.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest + Testing Library
npm run test:e2e # Playwright (первый раз: npx playwright install chromium)
npm run build    # production-сборка в dist/
```

Сборка статическая (HashRouter, `base: './'`), её можно выложить на любой хостинг.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` при каждом пуше в `main` прогоняет тесты, собирает проект и публикует сайт.
Один раз включите: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Сайт будет доступен по адресу `https://<user>.github.io/f1app/`.

Отчёт о тестировании и сверке с официальными данными — [docs/TESTING.md](docs/TESTING.md).

Данные Jolpica-F1 распространяются по [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/): только некоммерческое использование и обязательное указание источника. Лимиты без токена: 4 запроса/с, 500 запросов/ч.

## Страницы

| Маршрут | Что показывает |
| --- | --- |
| `#/{season}` | Главная: следующий этап, подиум последнего, лидеры зачётов |
| `#/{season}/calendar` | Календарь с фильтром по статусу |
| `#/{season}/race/{round}` | Расписание сессий, результаты гонки, квалификации, спринта |
| `#/{season}/drivers` | Личный зачёт: поиск, сортировка |
| `#/{season}/constructors` | Кубок конструкторов |
| `#/{season}/driver/{id}` | Профиль пилота: биография, сезон по этапам, победы и гонки за карьеру |
| `#/{season}/constructor/{id}` | Профиль команды: пилоты сезона, результаты по этапам, победы за карьеру |
| `#/{season}/circuit/{id}` | Профиль трассы: место, карта, этап сезона, победители по годам |
| `#/about` | Источник данных, правила статусов, кэш, часовой пояс |

## Структура

```
src/
  api/client.ts      HTTP: тайм-аут, 429 + Retry-After, битый JSON, кэш 10 мин, запасные данные из localStorage, ≤4 запроса/с
  api/jolpica.ts     Эндпоинты и пагинация → внутренняя модель
  domain/types.ts    Нормализованная модель (отсутствующие поля = null)
  domain/mappers.ts  Разбор JSON
  domain/status.ts   Статус этапа: завершён / идёт / предстоящий / ждём результаты
  domain/format.ts   Даты в локальной зоне с сохранением UTC
  hooks/             Загрузка данных, привязанная к сезону
  components/        Таблица с сортировкой, состояния загрузки/ошибки, строка источника
  pages/             Страницы
```

## Как приложение обращается с данными

- Очки и позиции берутся из standings источника, приложение их не пересчитывает.
- Этап считается завершённым, если источник уже учёл его в зачёте; остальные статусы определяются по датам. Отменённые или перенесённые этапы не отмечаются: Jolpica такого статуса не передаёт.
- Под каждым блоком данных указаны источник, время загрузки и кнопка «Обновить».
- Если API недоступен, показываются последние сохранённые данные с предупреждением.
