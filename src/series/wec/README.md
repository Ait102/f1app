# WEC — стартовая точка

Здесь будет раздел **FIA World Endurance Championship**. Пока папка пустая: работа начинается с выбора источника данных.

## Как устроен проект

```
src/
├─ api/client.ts     общий HTTP-клиент: тайм-аут, 429, кэш, запасные данные (источник передаётся параметрами)
├─ api/types.ts      Fetched / DataMeta — результат любого запроса
├─ components/       общие: DataState, SortableTable, Layout, ui.tsx (Stat, SearchBox, Moment, PointsWithBar)
├─ hooks/            общие: useResource (загрузка по ключу), useNow
├─ lib/format.ts     даты, часовой пояс, очки
├─ styles/           общие стили
└─ series/
   ├─ f1/            готовый раздел Formula 1 — образец
   └─ wec/           ← вы здесь
```

Правило: `series/wec` может брать всё общее из `src/` и **ничего** из `series/f1`. Если что-то из F1 нужно WEC — сначала переносим это в общую часть.

## Что повторить по образцу F1

| В F1                               | Для WEC                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| `f1/api/jolpica.ts`                | `wec/api/<источник>.ts` — эндпоинты через `createClient({ baseUrl, provider })` |
| `f1/domain/types.ts`, `mappers.ts` | своя модель: класс, экипаж из 2–3 пилотов, номер машины, длительность гонки     |
| `f1/domain/status.ts`              | статусы этапов (гонки идут часами — «Идёт» считать иначе)                       |
| `f1/hooks/data.ts`                 | хуки загрузки поверх общего `useResource`                                       |
| `f1/pages/`                        | календарь, этап с результатами по классам, зачёты                               |
| `f1/contract/`                     | проверки живого API источника                                                   |

## Порядок работы (тот же SDLC)

1. **Discovery.** Найти источник данных WEC с понятной лицензией, сделать 4–5 пробных запросов: календарь, результаты гонки, зачёты. Записать, каких полей нет.
2. **Модель.** Описать типы с nullable-полями: отсутствующие данные не придумываются.
3. **API и разбор.** Модуль источника + мапперы + unit-тесты на разбор.
4. **Страницы.** Сначала календарь и результаты, потом зачёты по классам.
5. **Подключение к сайту.** Маршруты `#/wec/...` в `src/App.tsx`, переключатель F1 / WEC в шапке (`src/components/Layout.tsx` — сейчас в нём меню и выбор сезона F1).
6. **Тесты и сверка** с официальными результатами.

## Правила, общие для всех разделов

- Очки и позиции — как у источника, без пересчёта.
- Нет данных — «—» или «Данные недоступны», не выдуманные значения.
- Под каждым блоком данных — источник и время загрузки (`DataState` делает это сам).
- Ключей API во фронтенде нет. Если источник требует ключ — нужен серверный прокси.
